# TripEasy 추천 카드 최종 UI 검증

검증일: 2026-10-13 (Asia/Seoul)
로컬 원본 및 ‘TripEasy-공개배포’ 폴더에 반영했습니다. 공개 Vercel 사이트의 이번 UI 반영은 폴더 재업로드 후 확인해야 합니다.

## 원인과 수정

식사·날씨를 담은 .card-extra-facts에 큰 화면의 .top-results .trip-metrics>div 규칙이 적용되면서 자식 두 항목이 22/46px 정도의 좁은 칸에 들어갔습니다. 좁은 칸에서 단어가 글자 단위로 줄바꿈되고 아이콘이 겹쳤습니다.

기존 CSS 규칙과 충돌하지 않는 trip-facts/trip-fact로 분리했습니다. 걷기·휴식·차량·식사·날씨 모두 ‘22px 아이콘 / 항목명 / 남은 전체 폭의 값’ 규칙으로 정렬합니다. 한글 keep-all, 정상 단어 줄바꿈과 기온·식사 단위의 nowrap을 조합했습니다. 식사와 날씨를 좁은 병렬 칸에 넣지 않습니다.

상단 추천 띠·이미지 높이·제목 공간·정보 행·가격/버튼의 위치를 정리해 상품끼리 쉽게 비교할 수 있도록 했습니다. 1440px은 3열, 1024px은 2열, 390px은 1열입니다. 기존 베이지·브라운·딥그린과 큰 글씨 기능을 유지했습니다.

## 표시 정리

카드·비교 화면에서 반복 DEMO/데모 예시 배지, 상태별 반복 배지, 출처 장문, 중복 설명을 제거했습니다. 식사는 한식·현지식 요약, 비교에서는 자유식 포함 전체 구성을 표시합니다. 날씨는 도시·월·기온을 한 줄 중심으로 표시합니다. 실제 예보 조회·우선 표시 로직은 그대로입니다.

추천 이유와 주의 조건은 접을 수 있으며 쇼핑·항공도 해당 영역에서 유지합니다. 자세한 데이터 구분은 상세/서비스 안내에 남겼고 가상 정보가 실제 검증값이라는 주장이나 공식 기상 예보라는 문구는 추가하지 않았습니다. 기존 예약 페이지 이동과 실제 청구 없음 안내를 유지합니다.
