# TripEasy 글로벌 비즈니스 발표용 MVP 개선 결과

작성일: 2026-10-13 (Asia/Seoul)

배포 상태: 로컬 원본과 공개 배포용 코드 개선 완료. 현재 Vercel 프로젝트에 새 버전 업로드는 아직 완료되지 않았습니다. 이 보고서의 개선 URL은 재배포 후 사용해야 합니다.

## 1. 실제로 구현 완료한 기능

- 서비스 범위를 국내외 패키지여행 비교·추천으로 수정. 일본은 현재 시연 사례라고 명시.
- 국가 필드를 두 글자 국가 코드로, 지역을 제한 없는 검증된 문자열로 확장. 목록·조건 입력의 국가/지역 옵션은 실제 등록 상품에서 계산. 관리자 국가·지역 편집 지원.
- 상품 수를 그대로 유지: 실제 조사 상품 6개, 일본 가상 상품 12개. 미확보 국가의 상품을 추가하지 않음.
- 이동 수치별 ‘확인된 정보 / 지도 기반 추정 / 데모 예시 / 정보 없음’ 구분을 위한 구조와 표시 추가. 현재 실제 지도 계산 기록은 없음.
- 확인된 실제 수치는 항목별 출처 URL·확인일·근거를 요구. 지도 추정은 추가로 공급자를 요구. 실제 상품에 데모 수치 등록을 차단.
- 근거 없는 기존 추정 값은 공개 숫자·추천·필터·비교에서 제외. 데모의 수치는 실제 확인값으로 바꾸지 않고 데모로 표시.
- 사용자 화면의 ‘근거 신뢰 xx%’ 삭제. 조건 일치 점수, 계산 기준, 구체적인 추천 이유, 예산·기간·선호 불일치와 정보 부족 표시.
- 2~3개 상품 비교에 보행·휴식·차량 수치와 상대 막대, 데이터 상태·수치별 근거 보기, 관광 스타일 추가. 발표 화면 토글로 사진과 중복 설명 축소.
- 현재 규칙 기반 추천/파서와 향후 AI·지도 API 개발을 구분하는 설명 영역 추가.
- 발표 시연 시작과 추천 결과 바로 보기, 추천 상위 3개 바로 비교하기 추가. 시연 예시 조건은 별도 sessionStorage에 보관하고 종료 시 일반 조건 복원.
- 베이지·딥그린, 귀여운 로고, 큰 글씨와 주요 흐름 유지.

## 2. 유지한 기존 기능

조건 입력 4단계, 필수 장소 입력과 별칭 처리, 예산·지역·기간·걷기·휴식·여행사·온천 필터, 추천 및 정렬, 최대 3개 비교, 상세·부모님 일정표·링크 공유, 항공 시각·기체/좌석 정보, 계절 기후·선택 날씨 예보, 가상 예약/결제.

원본 프로젝트의 관리자 인증·CRUD·JSON/CSV 업로드·규칙 기반 일정표 파서 및 DB 저장은 유지. 공개 발표용 버전은 기존처럼 읽기 전용 상품과 브라우저 조건 저장을 사용.

## 3. 아직 구현하지 못한 기능과 API 제약

- 실제 AI 모델을 통한 일정 분석: 미연결. 현재 파서는 등록된 일본 명소 문자열과 버스 표현을 추출하는 규칙 기반 코드이며, 보행·휴식 수치를 생성하지 않음.
- 실제 지도 거리 산출: 미연결. src/lib/maps.ts는 RouteInput/공급자 인터페이스만 있으며 null/unknown을 반환.
- 환경 점검: 로컬 .env 계열에 사용 가능한 GOOGLE_MAPS_API_KEY·LLM_API_KEY가 확인되지 않음. 값은 출력하거나 보고서에 기록하지 않음. Vercel 환경 변수는 계정 연결이 없어 조회하지 못함.
- 구현 가능성: 지도 Routes API의 WALK/DRIVE 계산을 서버 공급자로 추가할 수 있음. 먼저 공급자 설정·키·이용 조건을 확인하고, 관광지 이름을 실제 Place ID/좌표로 식별해야 함. 현재 일정 데이터는 장소명과 텍스트만 있어 승하차 위치·내부 동선·도보 여부를 별도로 확인해야 함.
- 지도 API가 반환하는 경로는 현장 동선·계단·휴식·시니어 적합성 검증 결과가 아님. 확인된 도보 구간만 계산하고 미확인 구간은 unknown으로 유지해야 함.
- 국내·대만·베트남·유럽의 실제 상품·기후 공급자는 미확보. 국가/지역 등록 구조만 확장했으며 미확보 상품은 생성하지 않음.
- 외화 환산은 미구현; 현 가격과 예산은 KRW 기준.
- 공식 여행사 제휴·실제 예약·결제·자동 크롤링은 미연결.

API 참고: [Google Routes computeRoutes](https://developers.google.com/maps/documentation/routes/reference/rest/v2/TopLevel/computeRoutes), [계산 개요](https://developers.google.com/maps/documentation/routes/compute-route-over).

## 4. 데이터 출처와 가상 데이터 구분

실제 조사 상품은 2026-10-10 공식 공개 페이지/검색 색인 확인 기록이며 docs/RESEARCH.md에 여행사·상품별 URL·한계가 있음. 보행·차량·휴식은 실제 근거가 없어 null/unknown을 유지. 현재 판매·가격·제휴를 보장하지 않음.

데모 상품 12개는 기존 가상 가격·일정·항공·이동 수치를 유지하고 상태를 demo로 명시. 추가 실측·지도·AI 결과 없음.

기후: 일본 기상청 1991~2020 평년값, 실제 날짜 예보와 구분. 선택 실시간 예보: Open-Meteo, 추천 점수에는 미반영. 테스트 예보 응답은 모킹으로 확인했으며 실시간 외부 API 가용성 검증이 아님.

사진: Unsplash 참고 사진과 AI 생성 온천 분위기 이미지. 실제 상품·숙소 사진 아님.

## 5. 발표 URL과 클릭 순서

재배포 후 기본 주소: https://tripeasy-three.vercel.app/

- 60~90초 전체 흐름: 홈 → ‘발표 시연 시작하기’ → 기본 예시 조건으로 다음 3회 → ‘부모님께 맞는 여행 추천받기’ → ‘추천 3개 한눈에 비교하기’ → 추천 이유/주의할 조건과 하루 이동·휴식 수치 설명.
- 빠른 결과: https://tripeasy-three.vercel.app/trips?recommended=1&demo=1
- 비교 바로 보기: https://tripeasy-three.vercel.app/compare?ids=demo-01,demo-02,demo-03&demo=1
- 시연 종료: ‘시연 종료 · 내 조건 복원’.

현재 공개 주소에는 이전 버전이 남아 있을 수 있으므로 개선 경로는 업로드 완료 후 확인해야 함.

재배포: https://vercel.com/trip-easy/tripeasy 화면에 바탕화면 ‘TripEasy-공개배포’ 폴더를 드래그해 기존 Production Deployment 갱신. 새 프로젝트를 만들 필요 없음. Next.js / npm run build / 환경 변수 추가 없음. Ready 뒤 Visit과 시크릿 창에서 확인.

## 6. PPT에서 수정할 기술·기능 표현

- ‘일본 전용 서비스’ → ‘국내외 패키지여행 비교 플랫폼, 현재 일본 상품으로 시연’.
- ‘AI 기반 자동 보행 분석 제공’ → ‘현재는 저장된 데이터 기반 비교, AI·지도 자동 분석은 향후 개발’.
- ‘연령·건강 상태 맞춤 매칭’ → ‘걷기·휴식 선호, 예산·기간에 따른 조건 일치 추천’.
- ‘부모님 체력에 안전한 여행’ → ‘입력한 여행 조건에 맞는 상품과 그 판단 근거’.
- ‘신뢰도 81%’ → ‘항목별 데이터 상태와 출처 표시’.
- ‘지도 기반 2.4km 산출’ → 지도 연동 전에는 ‘발표용 예시 보행 거리’.
- ‘제휴 수수료 수익’ → ‘향후 여행사 예약 연계 수수료 모델’.
- ‘예약·결제 기능 완료’ → ‘가상 예약·결제 화면 시연, 실제 청구 없음’.
