## 미구현 또는 제한

- 실시간 여행사 가격·출발 재고·출발일별 옵션 자동 갱신: 미구현
- 공식 API/제휴 크롤러: 정책/권한 미확인으로 비활성화
- 실상품 상세 일정 및 정량 보행/차량/휴식 평가: 공개 근거 부족. 정보 확인 필요로 유지
- Google Places/Routes 실제 호출: 미연결, 인터페이스만 준비. API 키를 넣는 것만으로 활성화되지 않음
- LLM 호출: 미연결, 규칙 파서 사용. 알려진 관광지 사전 외의 장소는 자동 추출되지 않을 수 있음
- 관리자 CSV: product_json 단일 열 규격 지원, 여행사별 임의 열 자동 매핑 미구현
- PostgreSQL 데이터 이전: 구조상 전환 가능, 실제 이전/검증 미수행
- 한국어 이외 언어, 타국 시장, 결제, 사용자 계정, 실제 예약: 미구현
- 외부 서버 배포: 미수행. 로컬 공유 링크는 동일 서버 접근 환경에서만 작동
- 분산 인증 제한, 상시 개인정보 만료 작업: 로컬 단일 프로세스 수준
- 전체 shadcn/ui 카탈로그: 미설치. Button 패턴/Radix Slot 적용

## 2026-10-10 추가 기능
- `/preferences` 여행 조건 단계: 필수 방문 장소 최대 10곳, 저녁·심야 회피, 광동체 선호, 계절 날씨 반영. 기존 저장 선호는 새 필드 기본값으로 호환.
- 필수 장소는 모든 입력을 방문 목록/일자별 stops와 정확히 매칭. 표기 별칭 지원, 부분 문자열이나 지역명으로 명소 포함을 추정하지 않음. 실제/DEMO 탭 모두 적용, 조건 해제 가능.
- 상품 상세·부모님 화면: 왕복 현지 시각, 편명/기종/기체 분류, 비행 시간, 좌석 간격/폭/등급과 근거. 비교 표·상품 카드 요약 제공. 실제 6개 항공 정보는 확인 필요, DEMO 12개는 명확한 가상 가정.
- 관리자 구조화 항공 편집 폼, 방문 목록 및 완전성 표시, JSON/CSV 저장·가져오기 지원. 실제 항공 정보는 출처와 조사 시각 필수.
- JMA 1991–2020년 후쿠오카/오사카/삿포로 월 평년값. 출발일 우선, 희망 월 보조. 지역 전체/실제 날짜 예보로 표시하지 않음. 강수량은 월 누적, 최고/최저는 하루 평균값.
- `/api/weather`: 허용된 7도시만 조회, Tokyo 날짜 기준 여행 전체 기간이 16일 이내일 때 Open-Meteo 실시간 조회. 8초 타임아웃, 30분 캐시, 외부 오류를 정보로 생성하지 않음. 비상업 무료 API/CC BY 4.0 출처 표시. 상업 서비스는 이용 플랜 변경 필요.
- SQLite 변경 전 `/private/tmp/easy-trip-before-travel-info.db` 백업. `scripts/enrich-demo.ts`는 flights가 null인 기존 DEMO만 추가하여 관리자 기존 편집 유지. 새 설치 seed에도 새 필드 포함.


## easyTrip 프리미엄 시연 업데이트
- easyTrip 워드마크로 변경. 상품 목록은 DEMO 시연 탭을 기본값으로 사용.
- 사용자가 요청한 시연 데이터를 12개 가상 상품에 적용. 실제 6개 데이터 및 출처 유지. 기존 DB는 /private/tmp/easy-trip-before-premium.db에 백업.
- 조건 일치도는 가중 평균 fit, 근거 신뢰는 confirmed 1 / estimated 0.7 / unknown 0으로 별도 표시. 미확인 항목의 fit은 0으로 유지하며 최소 80점 보정이나 랜덤 점수는 사용하지 않음. 기본 조건의 가상 데이터 평균 89.4점, 범위 71~100점.
- 필터 결과의 조건 점수 최고 상품 한 개만 BEST MATCH, 금색 테두리와 리본. 가격 정렬로 변경해도 최고 일치 상품을 유지. 홈 추천도 실제 조건 점수 순.
- /booking/[id]: 가상 상품 예약·결제 화면 체험. 인원 선택/총금액 계산/가상 상품 확인/예약 체험 완료. 카드정보 수집·결제·실예약 없음. 실제 상품은 공식 여행사 URL로 바로 이동하는 CTA.


## 어르신 가독성 개선
- 기본 root 글씨 20px, 큰 글씨 추가 확대 24px. 핵심 본문 20px 내외, 카드 제목 모바일 27px, 지표 약 22px, 버튼 높이 60px 이상.
- 데스크톱 카드 2열/모바일 1열. 숫자·단위와 보행 부담 설명을 분리하고 큰 가격/추천 점수 표시. 항공/날씨 및 추천 근거는 펼쳐보기로 유지.
- 대비와 행간·여백 개선. 홈/목록의 주요 영어 설명을 한국어로 변경. 최상위 추천 리본은 ‘가장 잘 맞는 여행’.
- 모바일 비교표는 상품 이름을 각 값에 표시하고 1열로 전환. 입력/선택/체크박스 및 선택 카드 크기 확대.
- Chromium 10개 흐름 통과, axe 접근성 위반 0, 기본/추가 큰 글씨 모바일 6개 경로 수평 넘침 없음.
